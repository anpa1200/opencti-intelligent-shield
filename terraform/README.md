# Terraform — OpenCTI Intelligent Shield on GCP

Provisions a single Compute Engine VM that auto-deploys the full OpenCTI
Intelligent Shield lab (core stack + feed connectors + Claude AI enrichment
connector) via Docker Compose on first boot.

## What it creates

- A dedicated VPC network + subnet
- A reserved external IP
- Firewall rules (SSH `22`, OpenCTI UI `8080`, optionally admin consoles)
- One Ubuntu 22.04 VM (default `e2-standard-8`, 200 GB SSD) that:
  - tunes the kernel for Elasticsearch (`vm.max_map_count`, file limits)
  - installs Docker + Compose plugin
  - clones this repo
  - writes a `.env` with **auto-generated** strong secrets and UUID connector IDs
  - brings up the core stack, connectors, and (optionally) the AI connector

All passwords/tokens are generated by Terraform — no secrets are committed.

## Prerequisites

- A GCP project with billing enabled
- `gcloud` authenticated: `gcloud auth application-default login`
- Terraform >= 1.3

## Usage

```bash
cd terraform
cp terraform.tfvars.example terraform.tfvars
# edit terraform.tfvars: set project_id, lock down source ranges, add API keys

terraform init
terraform apply
```

After ~10–20 min (first boot pulls images and Elasticsearch initializes), open
the UI:

```bash
terraform output opencti_url
terraform output -raw opencti_admin_password   # if auto-generated
```

Watch first-boot progress:

```bash
$(terraform output -raw ssh_command)
sudo tail -f /var/log/opencti-bootstrap.log
```

## Notes

- **Access control:** `ssh_source_ranges` and `app_source_ranges` default to
  `0.0.0.0/0` so the lab is reachable out of the box. Restrict them to your IP
  (`x.x.x.x/32`) for anything beyond a throwaway lab.
- **Sizing:** the stack runs Elasticsearch, OpenCTI (8 GB Node heap), 3 workers
  and several connectors. `e2-standard-8` (32 GB) is comfortable;
  `e2-standard-4` (16 GB) is the bare minimum.
- **API keys:** `anthropic_api_key`, `alienvault_api_key`, `nvd_api_key` are
  optional. If omitted they are written as `CHANGE_ME` in the VM's `.env`; SSH
  in, edit `/opt/opencti/.env`, and restart the relevant compose stack.
- **Base URL:** `OPENCTI_BASE_URL` is pinned to the reserved external IP so the
  UI login/redirects work. If you later put a domain/TLS in front, update it.
- **Tear down:** `terraform destroy` removes everything including data.
